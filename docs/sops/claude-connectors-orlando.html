Connect your Claude to Slack and Shopify

Step-by-step setup for Orlando. When you finish, you can ask Claude about Slack threads and client store orders without leaving the chat. It takes about 20 minutes.

Owner: GlyVersion 1 · Nov 3, 2026Pictures are drawings of the screens, not screenshots

Overview

What gets connected

SlackConnect in Claude

Claude can search and read ShipMode channels, DMs and files you can already see.

ShopifyConnect in Claude, view only

Claude can look up orders, products and stock in the client stores you have staff access to.

ShipSidekickNot connected

Claude has no ShipSidekick connector. Keep using ShipSidekick in your browser as usual. See Part 4.

Part 0

Before you start

Tick these off. If one is missing, message Gly in Slack before going further.

Part 1

Open Claude's Connectors page

Step 1
  1. 1Go to claude.ai/customize/connectors. You can also click Customize in the left sidebar, then Connectors.
  2. 2Click Discover to see the list of available connectors.
  3. 3Use the Search connectors box to find each app below.

Leave this tab open. You'll come back to it for Slack and Shopify.

Part 2

Connect Slack

Step 2

Find Slack and click Connect

  1. 1Type Slack in the search box.
  2. 2Click Connect (or Connect to Claude).

See "Request" instead of Connect? Your Claude team owner hasn't turned on Slack yet. Click Request and message Gly. Stop here until it's approved.

Step 3

Approve on Slack's page

  1. 1A Slack page opens. Check that the workspace at the top right says ShipMode. If it shows a different workspace, use the menu there to switch.
  2. 2Read the list of what Claude can see, then click Allow.

If Slack asks you to sign in first, use your ShipMode Slack email.

Step 4

Check it says Connected

You land back on Claude's Connectors page. Slack now shows Connected under Your connectors, and its button changes to Disconnect. Don't click that.

Step 5

Test it in a new chat

  1. 1Start a New chat. Click + at the bottom left of the message box.
  2. 2Click Connectors and make sure Slack is switched on.
  3. 3Send this message:
Summarize the last 10 messages in #no-movement

The first time, Claude asks permission to use Slack. Click Allow once. If you get a summary back, Slack is done.

Part 3

Connect Shopify (view only)

Read this first. The Shopify connector can change a store: edit products, set inventory, create discounts. ShipMode only looks at client stores. Two things keep it that way:

1. Your Shopify staff login has view-only permissions, so Shopify itself blocks changes.
2. You never ask Claude to change anything in a store. If Claude ever asks you to approve a change, click Deny.

Step 6

Find Shopify and click Connect

  1. 1Back on Connectors, search for Shopify.
  2. 2Click Connect (or Connect to Claude).

Same as Slack: if you see Request, click it and message Gly.

Step 7

Sign in to Shopify and pick a store

  1. 1Shopify's sign-in page opens. Use the email the store owner invited as staff, not a personal or client owner login.
  2. 2If you have access to more than one store, pick the client store you want first.
  3. 3Review the access screen and click Approve (it may say Install or Connect).

You return to Claude, and Shopify shows Connected, like Slack in Step 4.

Step 8

Test it with a read-only question

In a new chat, turn on Shopify under + → Connectors and send:

How many orders did this store get yesterday? Just read, don't change anything.

Click Allow once when Claude asks to look up orders. To work on another client, ask: Switch to the <client name> store.

Click Deny if a permission box names an action like update product, set inventory, create discount or anything that writes. Then tell Gly what you asked.

Part 4

ShipSidekick stays separate

Claude has no ShipSidekick connector. The only way to link them is a ShipSidekick API key, and ShipMode keeps those keys locked on the server. So:

  • Keep using ShipSidekick in your browser for labels, shipments and stock, exactly as you do now.
  • To check ShipSidekick stock or shipments against the Sheet, use the ShipMode workspace (Inventory and No Movement tabs). It already reads ShipSidekick, view only.
  • To get Claude's help with a ShipSidekick screen, copy the text you need (an order number, a tracking status) into the chat. Never paste API keys, passwords or a full customer list.

Part 5

Rules for using it

Do
  • Ask Claude to find, read, count and summarize: threads, orders, stock levels, tracking.
  • Click Allow once for lookups.
  • Check anything important against the source (Sheet, Shopify, ShipSidekick) before you act on it.
  • Turn off connectors you don't need in that chat.
Don't
  • Ask Claude to edit, cancel, refund, tag or fulfill anything in a client store.
  • Let Claude post in Slack for you. Read its draft, then post it yourself.
  • Choose Always allow for Shopify.
  • Paste passwords, API keys or client exports into a chat.
